# Data Source

The CSV files in this directory are derived from `db/wilayah.sql` in
[cahyadsn/wilayah](https://github.com/cahyadsn/wilayah), which follows
Kepmendagri No. 300.2.2-2430 Tahun 2025.

Changes from the original: codes are split into one file per level with the
dots removed, names are converted to upper case, and extra whitespace in names
is removed.
